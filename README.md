## 这是什么

**第二份研究，从回溯性重构格式包衍生出来。**

回溯性重构解决：**怎么让结论保持可被推翻**（机制）。
匮乏解决：**为什么需要猜**（燃料）。

**没有缺口 → 不会猜 → 不是人。**

## 和「回溯性重构 · 格式包」一起用

**→ `github.com/QiDouZu/retcon-form`**（那边是正文机制，这边是燃料）

| 你要的 | 用哪份 |
|---|---|
| 让 AI 读到的结论是"进行时" | **retcon-form**（格式 + 壳 + 提示词） |
| 让 AI 有缺口、会猜、会长 | **这份**（匮乏） |
| 两个都要 | **两个都拷**：retcon 的壳 + 这份的判据，连起来用 |

**结合点**：retcon 的六环里，③压缩之后是④猜——**④猜为什么发生？**就是因为匮乏：缺口逼你往里走。retcon 给了"猜完"的格式，匮乏给了"为什么猜"。

**一句话**：retcon 给"猜"一个可被推翻的壳，匮乏给"猜"一个缺口。
